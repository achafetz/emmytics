# Key Events in Applicant Journey (With Line Breaks)

A version of
[`key_events_clean`](https://aaron-chafetz.com/emmytics/reference/key_events_clean.md)
with line breaks (`\n`) replacing spaces for multi-line display in
visualizations with limited horizontal space.

## Usage

``` r
key_events_clean_br
```

## Format

A character vector with 7 event names containing line breaks (`\n`)
instead of spaces for vertical display.

## Details

This vector is derived from
[`key_events_clean`](https://aaron-chafetz.com/emmytics/reference/key_events_clean.md)
by replacing spaces with line breaks. Use this version when creating
visualizations with limited horizontal space where vertical text
wrapping is preferred.
