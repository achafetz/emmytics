# EMMY State Pilot Periods

The following dataset notes the pilot periods run in various states.

## Usage

``` r
pilot_pds
```

## Format

a data frame with 5 rows and 5 columns

## See also

[`set_pilot`](https://aaron-chafetz.com/emmytics/reference/set_pilot.md),
[`return_latest_pilot`](https://aaron-chafetz.com/emmytics/reference/return_latest_pilot.md)

- name:

  Name of the pilot

- state:

  Two letter state abbreviation of the pilot state

- client_agency:

  The state agency code used in Mixpanel

- start_date, end_date:

  start and end period of the pilot, dates

- pilot:

  month and year of pilot
