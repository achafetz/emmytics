# Key Events in Applicant Journey (Cleaned for Display)

A cleaned version of
[`key_events`](https://aaron-chafetz.com/emmytics/reference/key_events.md)
with spaces added for improved readability in visualizations and
reports. Event names are transformed from camelCase to human-readable
format.

## Usage

``` r
key_events_clean
```

## Format

A character vector with 7 cleaned event names with spaces added between
words for display purposes.

## Details

This vector is derived from
[`key_events`](https://aaron-chafetz.com/emmytics/reference/key_events.md)
using the
[`clean_events()`](https://aaron-chafetz.com/emmytics/reference/clean_events.md)
function to add spaces between words. Use this version when creating
visualizations or reports where readability is important.
